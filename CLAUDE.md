# Портфолио — Анастасия Плетнер (Pletner Design)

Личный дизайн-портфолио на React 19 + TypeScript + Vite. Витрина концептов
UI/UX-проектов ("Аптеки рядом", "HackWish", "Movie Mate", "CampaignCore").
Визуальный стиль — коллаж/скрапбукинг (вырезки из бумаги, нитки, звёзды).

## Структура

- `src/components/Header`, `src/components/Footer` — общий каркас (шапка с лого, футер со ссылками)
- `src/pages/Main` — главная: `Hero` (о себе) + `MainContent` (грид проектов)
- `src/pages/ProjectPage` — страницы отдельных кейсов (Apteki, Dashboard и т.д.)
- `src/data.ts` — список проектов для карточек на главной
- `src/UI` — общие компоненты (`Button`) и `sharedStyles.module.css` (обёртки, отступы, акцентный цвет)
- CSS Modules везде, без глобального стейт-менеджмента

## Известные особенности / договорённости

- Карточки HackWish и Movie Mate в `data.ts` временно ведут на `AptekiPage`
  (отдельные страницы для них ещё не написаны) — осознанная временная заглушка,
  не трогать без явного запроса.
- Раздел с проектами (`data.ts`, `Project.tsx`, страницы кейсов) — просили не
  ломать при переделке хиро-секции; трогаем только раскладку грида, не контент.
- Header **не** fixed (по просьбе — не должен залипать при скролле), фон
  header и фон страницы — один и тот же `var(--color-bg)`, чтобы не было шва.
  `.paddingTop` в `sharedStyles.module.css` теперь просто фиксированный
  небольшой отступ (40/20px по брейкпоинтам), не завязан на высоту header.
- Акцентный цвет вынесен в CSS-переменные в `src/index.css` (`--color-accent`,
  `--color-accent-dark`, `--color-accent-tint`) — сейчас розовый (#C04A6E),
  подобран по цвету кружочков на фото в Hero (сэмплировано скриптом из пикселей
  картинки). Менялся несколько раз по ходу правок — если попросят другой
  оттенок, смотреть на эти три переменные.
- Текстура фона (`body::before` в `index.css`) — реальное фото мятой бумаги
  (`public/image/paper-texture.png`), скачано с Unsplash (свободная лицензия,
  без атрибуции) с явного разрешения пользователя, обработано локально
  (Python/PIL): high-pass фильтр выделяет только заломы, из яркости сделан
  альфа-канал → полупрозрачный PNG на тёмно-бежевый цвет, `mix-blend-mode:
  multiply` + `opacity: 0.45` для мягкости.

## История изменений в этой сессии

1. **Редизайн главной**: боковое sticky-меню (`AsideAbout`) заменено на
   полноширинный `Hero`-блок сверху + грид проектов снизу (был:
   flex-сайдбар слева + грид справа).
2. Лого в шапке и заголовок на главной стали картинками (`logo.png`,
   `title.png`), вместо текста. Фото — тоже картинка (`photo.png`), все три —
   коллажи в стиле сайта, лежат в `public/image/`.
3. Кнопка "Пригласить на собеседование" перенесена из шапки в Hero, в один ряд
   с кнопкой "Посмотреть CV" (шапка теперь — только центрированное лого).
4. Ссылки (Telegram/LinkedIn/email) в Hero сделаны кнопками-пилюлями
   (мягкая заливка акцентным цветом), кнопка приглашения — акцентная заливка,
   CV — с бордером (добавлен `secondary`-вариант в `Button`).
5. Грид проектов на главной: с `auto-fill` на явные 3 колонки; карточка
   "Другое" перенесена внутрь грида и растянута на 2 колонки
   (первая строка — 3 карточки, вторая — 1 стандартная + 1 широкая).
6. Смена акцентного цвета: синий (#5790B4) → терракотовый → затем розовый
   (#B5525F), подобранный по цвету кружочков на фото в Hero — через
   CSS-переменные в `index.css`.
7. `.hero__content` растягивается на всё оставшееся место (`flex: 1 1 auto`)
   вместо фиксированного `max-width` — так фото и текстовый блок прижаты к
   противоположным краям контейнера (отступы слева/справа симметричны), а
   сам текст внутри всё равно не растягивается благодаря `max-width` на
   `.hero__description`. (Пробовали `justify-content: space-between` на
   `.hero` — отменили, т.к. это ломало фиксированный gap между фото и
   текстом; вернулись к обычному gap + растягиванию контента.)
8. Отступы сверху/снизу у Hero увеличены (снизу 130px десктоп, сверху свой
   `margin-top` поверх `.paddingTop`).
9. Добавлен подзаголовок "UI/UX дизайнер с опытом 2,5 года" под
   картинкой-заголовком (`.hero__subtitle`).
10. Header перестал быть `position: fixed` — прокручивается вместе со
    страницей. Лого чуть уменьшено (64→56px десктоп, 40→36px мобилка).
11. На фон сайта добавлена фотореалистичная текстура мятой бумаги (см. выше,
    заменила более раннюю версию на SVG-шуме — от неё отказались, т.к.
    просили именно "фотку" текстуры).
12. Header сделан прозрачным (`background-color: transparent`) — сливается
    с текстурой фона вместо сплошной заливки `--color-bg`.
13. Фон-текстура (`body::before`) больше не `position: fixed` (был пришпилен
    к вьюпорту) — теперь `position: absolute` и скроллится вместе со
    страницей; `background-repeat: repeat` с тайлом 480×672px вместо
    растягивания одной картинки на весь экран (`cover`).
14. Текстура показалась слишком заметной — накидала 3 варианта обработки
    (сильнее blur, крупнее тайл, разная непрозрачность) в виде артефакта
    с полноразмерными превью хиро-блока на каждой странице. Выбран
    **вариант B**: `public/image/paper-texture.png` заменён на более мягкую
    версию (blur radius 28 при генерации из high-pass фильтра), тайл
    640×896px, `opacity: 0.22` в `index.css` (просили ещё прозрачнее, чем
    показанный в артефакте .32). Если ещё раз попросят другой вариант —
    само демо больше не актуально (файл заменён), нужно будет
    перегенерировать из `crumpled-paper-source.jpg` (в этой сессии лежал в
    scratchpad, в проекте не сохранён).

## Инструменты/команды

- `npm run dev` — дев-сервер (Vite, порт 5173)
- `npm run build` — `tsc -b && vite build`
- `npm run lint` — ESLint (в проекте есть готовые ошибки `no-irregular-whitespace`
  из-за неразрывных пробелов в русском тексте — это осознанная типографика,
  не баг)
